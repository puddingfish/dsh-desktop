# DSH Desktop 使用说明

面向最终用户的操作手册：安装、启动、日常使用、自动更新、两个插件的配置、故障排查。

---

## 1. 安装

到 [Releases](https://github.com/puddingfish/dsh-desktop/releases) 下载最新版（写作本文时为 v0.1.2+）。

### 方式 A：NSIS 安装版（推荐日常使用）

1. 下载 `DSH-Desktop-Setup-<版本>.exe`，双击运行；
2. 按向导完成安装（无需管理员权限，默认装到 `%LOCALAPPDATA%\Programs\dsh-desktop`）；
3. 开始菜单 / 桌面出现「DSH Desktop」快捷方式，双击即可启动。

**更新全自动**：启动 10 秒后静默检查 GitHub Releases → 有新版自动后台下载 → 弹窗询问「现在重启更新 / 退出时自动安装」。

### 方式 B：绿色免安装版（U 盘 / 受限环境）

1. 下载 `DSH-Desktop-<版本>-portable-win-x64.zip`，解压到任意目录；
2. 双击解压目录里的 `DSH Desktop.exe` 即用，不写注册表。

**更新只提示不自动装**：发现新版本弹窗给出发布页链接（可选「忽略此版本（本次运行）」），下载新 zip 覆盖解压目录即可——你的数据都在 `%APPDATA%\DSH Desktop\`，覆盖解压目录不会丢任何东西。

> 两种形态的区分：NSIS 安装目录里有 `Uninstall *.exe`；没有卸载器的就是绿色版。

## 2. 首次启动会发生什么

启动页依次显示：**准备运行时 → 安装/升级 → 启动服务**。

- **运行时**：优先复用系统 Node.js（要求 22.19+ 或 24+）；没有或版本不符时自动从镜像下载独立运行时（约 30 MB，仅首次）。
- **DSH 本体**：经 npm 安装在 `%APPDATA%\DSH Desktop\dsh-runtime`，每次启动自动比对升级（托盘菜单也可手动「检查 DSH 更新」）。弱网环境可用 `DSH_DESKTOP_NPM_REGISTRY` 环境变量换 npm 源。
- **服务**：启动真实 `dsh web` 服务器，默认端口 3080；被占用时自动落到 3081+，窗口标题栏会显示实际端口对应页面。
- 任一阶段失败，启动页提供一键重试。

## 3. 日常使用

| 操作 | 行为 |
|---|---|
| 点窗口 **×** | 不退出——藏到系统托盘继续运行 |
| 双击托盘图标 | 重新显示窗口 |
| 托盘右键菜单 | 显示主窗口 / 检查更新 / 检查 DSH 更新 / 完全退出 |
| 标题栏 | 自定义样式，**跟随页面明暗主题**切换（不是系统主题）；Windows 风格最小化/最大化/关闭，双击标题栏最大化 |
| 退出时 | 若有已下载的更新（安装版），自动静默安装后退出 |

功能与网页版 `dsh web` **完全一致**——桌面端是官方 Web 版的外壳，会话、插件、设置全部共享 `~/.dsh`。

## 4. 自动更新细节

- **安装版**：electron-updater 接 GitHub Releases。启动 10 秒后静默检查（托盘菜单也可手动查）→ 后台下载到 `%LOCALAPPDATA%\dsh-desktop-updater` → 询问「现在重启 / 退出时自动安装」。
- **绿色版**：只检查与提示，绝不自动安装（绿色版的哲学：目录可随意搬迁，自动覆盖安装不合适）。
- **自定义更新源**（可选，自建服务器托管 `latest.yml` + 安装包）：编辑 `%APPDATA%\DSH Desktop\update-config.json`：

  ```json
  { "provider": "generic", "url": "https://your-server/dsh-desktop/" }
  ```

- 未配置仓库 / 网络不可达时**静默跳过**，不影响使用（原因见日志）。

## 5. 插件：模型路由（省钱）

**装好后哪里找**：侧边栏「模型路由」独立入口（新会话 → 任务看板 → SSH 之后），点击进入全屏配置页。页首显示当前「全局默认模型」作参考，Provider / 模型均为**下拉选择**（选项来自你已配置的模型列表）。

**它做什么**：按「任务类型」自动为每次 LLM 请求选模型——简单任务走便宜模型，重型任务走贵模型，不动 DSH 源码。

| 配置项 | 作用 |
|---|---|
| 启用路由 | 总开关 |
| 主会话 Provider/模型 | 未命中关键词规则时，主会话的基础模型；留空 = 不改写 |
| 子代理 Provider/模型 | 所有委派的后台任务（研究、独立小任务）**这是最大的省钱点**；留空 = 沿用继承模型 |
| 轻量规则 | 命中任一关键词（如「总结、写文档、翻译」）→ 路由到便宜模型 |
| 重型规则 | 轻量未命中时检查，命中（如「重构、架构、性能优化」）→ 路由到强模型 |

**行为要点**：

- 你在会话里**手动选过模型**的请求不会被干预（「尊重显式选择」默认开）；
- 每个回合在 `dsh web` 控制台输出一行路由日志（`model-router: … A/B -> C/D (light: keyword "总结")`），透明可审计；
- 路由器任何异常自动回退原配置，绝不阻断请求。

完整语义（含已知边界）见 [插件 README](../plugins/dsh-model-router/README.zh.md)。

## 6. 插件：mmx 图像理解（MiniMax VLM）

**前提**：本机装有 mmx CLI 且已登录（`npm install -g mmx-cli` → `mmx login`，需要 MiniMax 账号/订阅）。

**装好后哪里找**：设置 → Web UI 插件 →「图像理解（mmx）」卡片（mmx 路径、默认指令、超时、预览开关等）。

**怎么用**：

1. 聊天输入框的**原生图片按钮**选图发送——图片自动上传宿主附件库，改写为引用（图片字节不进会话日志）；
2. 模型调用 `describe_image` 时后端走本地 mmx（MiniMax VLM），只把文字答案带回会话；
3. 会话里的图片引用原地渲染为**缩略图**，点击看大图。

也支持本地图片绝对路径与 http(s) URL 直接传给 `describe_image`。

**本机没有 mmx？** 插件自动「静默休眠」：

- 安装脚本检测不到 mmx（npm 全局 / PATH 均无）→ 直接跳过安装，不写任何配置；
- 已安装的副本检测不到 mmx → 不注册 `describe_image` 工具、不显示设置卡片、不拦截图片发送，控制台零告警零报错——就像没装过一样；
- 状态可随时查询：`GET /mmx-vision/status` → `{"ok":true,"value":{"available":false,"mode":"absent"}}`；
- 装好 mmx 后重跑 `install-plugins.ps1` 并重启即恢复；想恢复原版 describe-image 见 [插件 README](../plugins/dsh-mmx-vision/README.zh.md#前置要求与软检测重要)。

## 7. 数据与日志位置

```
%APPDATA%\DSH Desktop\
├── config.json          # 工作区、端口、更新开关
├── update-config.json   # 用户自定义更新源（可选）
├── dsh-runtime\         # npm 管理的 DSH 本体（自动升级）
└── logs\
    ├── dsh-web.log      # 本次 dsh web 服务日志（mmx/模型路由日志也在这里）
    └── dsh-web.prev.log # 上次日志

%LOCALAPPDATA%\Programs\dsh-desktop\      # NSIS 安装目录
%LOCALAPPDATA%\dsh-desktop-updater\       # 安装版更新缓存
~/.dsh\                                   # 会话、设置、插件 profile（与网页版共享）
```

## 8. 故障排查

| 症状 | 处理 |
|---|---|
| 启动页卡在「准备运行时」 | 看日志；弱网设 `DSH_DESKTOP_NPM_REGISTRY=https://registry.npmmirror.com`、`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后重试 |
| 3080 被占用 | 自动落到 3081+，无需处理；想固定起始端口改 `config.json` |
| 侧边栏没有「模型路由」 | 插件装好后**需要重启** dsh web / DSH Desktop（运行中的实例不会热加载插件列表） |
| 设置里没有「图像理解（mmx）」卡片 | 本机没检测到 mmx CLI（静默休眠，属正常）；装好 mmx 重跑 `install-plugins.ps1` 并重启 |
| 带图消息报「找不到 mmx CLI」 | `npm install -g mmx-cli && mmx login`；或卸载插件恢复原版（见插件 README） |
| 更新没反应 | 未配置仓库/网络不可用时静默跳过；看 `%APPDATA%\DSH Desktop\logs\` 里 updater 日志 |
| 想彻底退出 | 托盘右键 → 完全退出（点窗口 × 只是藏到托盘） |
